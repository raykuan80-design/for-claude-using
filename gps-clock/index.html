    GitHub 連線

    Token 只存在這支手機，不會上傳到任何地方。

    地點

    名稱要和捷徑裡寫的完全一樣。設定座標後，網頁打卡會自動選最近的地點。

    課表

    打卡時間裡和課表重疊的部分，會改算到上課的地點（薪資照那個地點的設定）。課表外的時間留在原本打卡的地點。

    怎麼寫
    • 期間 2026-10-19 ~ 2026-12-13：每週固定課的有效期間
    • 每週一 18:00-21:00 名揚 國二理化：每週固定課（星期、時間、地點、課名）
    • 2026-10-19 停課 國二理化：這天停這堂課；只寫 停課 就是整天都停
    • 2026-10-26 13:30-16:30 名揚 國三理化：這天多一堂（補課、加課、調課）
    • 地點名稱要和上面「地點」裡的一樣，薪資才算得出來；括號裡的字是備註

    配對規則

    1. 建立 GitHub Token

    1. 打開 GitHub › 新增 Fine-grained token。
    2. Token name 填「打卡」，Expiration 選最長。
    3. Repository access 選「Only select repositories」，只勾你的紀錄存放庫（例如 gps-clock-data）。
    4. Permissions › Repository permissions › Contents 選「Read and write」。
    5. 按「Generate token」，複製 github_pat_ 開頭的那串文字。
    6. 回到「設定」分頁填入帳號、存放庫和 Token，按「連線並同步」。

    2. 加入主畫面

    用 Safari 開這個網頁，點「分享」›「加入主畫面」。之後從主畫面圖示打開。

    3. 建立捷徑「寫入打卡」（只要做一次）

    打開「捷徑」App › 右上角 ＋ 新增捷徑，名稱改成「寫入打卡」。依序加入下面的動作（在動作搜尋列輸入引號裡的關鍵字）：

    1. 搜尋「格式化日期」：點藍色的「日期」改選變數「目前日期」（不要在這裡打字），再把「日期格式」改成「自訂」，在下面多出來的格式欄位填入
      yyyy-MM-dd HH:mm:ss
    2. 搜尋「文字」：內容是「格式化的日期」變數、一個半形逗號 ,、再接「捷徑輸入」變數，看起來像 [格式化的日期],[捷徑輸入]。逗號不能少。
    3. 搜尋「Base64」：選「編碼」，輸入是上一步的「文字」。點開「顯示更多」，換行選「無」。
    4. 再加一個「格式化日期」：一樣選變數「目前日期」、日期格式「自訂」，格式欄位填
      yyyyMMdd-HHmmss
    5. 搜尋「取得 URL 內容」，網址先貼上下面這串（複製按鈕只會複製到 punches/），接著插入第 4 步的「格式化的日期」變數，最後再打 .csv：
      點開「顯示更多」：
      • 方法：PUT
      • 標頭：新增兩個
        Authorization ＝ Bearer github_pat_…（Bearer 後面一個空格，再貼上你真正的 Token）
        Accept ＝ application/vnd.github+json
      • 請求本文：JSON，新增兩個文字欄位：message ＝ 打卡，content ＝ 第 3 步的「Base64 編碼結果」。

    做好後可以先手動執行一次測試：點捷徑會要求輸入，填 上班,測試，然後回網頁按「同步」，應該會看到一筆「測試」的上班紀錄（測完到「紀錄」分頁刪掉）。

    4. 每個地點建立兩個自動化

    1. 捷徑 App › 自動化 › ＋ › 「抵達」，選地點（例如補習班），勾「立即執行」。
    2. 動作加「文字」，內容填 上班,地點名稱（例如 上班,板橋分校）。
    3. 再加「執行捷徑」，選「寫入打卡」，輸入是上一步的「文字」。
    4. 再建一個「離開」自動化，文字改成 下班,地點名稱。

    注意事項

    • 地點名稱在捷徑和「設定 › 地點」裡必須一字不差。
    • 手機要開「定位服務」，捷徑 App 的定位權限選「永遠」。
    • 沒網路時自動化會失敗；可以在網頁手動補打卡。網頁上打的卡在沒網路時會先存在手機，下次同步再上傳。
    • 紀錄存在你的私人存放庫 punches/ 資料夾，每次打卡一個檔案，可以直接在 GitHub 上看。
